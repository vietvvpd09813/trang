# Trang Web Dành Cho Trang

Đây là một trang web cá nhân được thiết kế đặc biệt dành cho Trang với các tính năng:

- Giao diện người dùng thân thiện và hiện đại
- Thiết kế responsive cho cả máy tính và điện thoại di động
- Hiệu ứng chuyển động mượt mà (animations, transitions)
- Các hiệu ứng tương tác với người dùng
- Content slider hiển thị hình ảnh và thông tin

## Công nghệ sử dụng

- HTML5
- CSS3 (Animations, Flexbox, Media Queries)
- JavaScript (ES6+)
- Font Awesome Icons

## Tính năng

- Hiển thị thông tin cá nhân
- Hiệu ứng trái tim và động vật dễ thương
- Trình chiếu hình ảnh với thông tin mô tả
- Modal với thông điệp đặc biệt
- Thiết kế đáp ứng trên mọi thiết bị

## Cách sử dụng

Mở file `index.html` trong trình duyệt web để xem trang web.
